# shadows-and-steel-playtest
Playtest edition of Shadows &amp; Steel, a card-driven strategy wargame. Play in your browser with no account or install, then send your notes to the design team at the end of each game.

This repository hosts a playtest build of a game in development, shared with invited playtesters for review.
